# ADR-014: Observability
**Status:** Accepted (P7) **Date:** 2026-07-19
Health+readiness endpoints, structured logs, request/job/claim IDs, metrics, alerts, bounded retention, error aggregation. Monitor: DB health, hot-wallet balance, reward-job, heartbeat-lag, queue depth, discord-bot, helpdesk. No secrets/private keys in logs. Rationale: operable + debuggable.
